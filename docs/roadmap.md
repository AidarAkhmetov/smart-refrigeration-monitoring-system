# Roadmap

| # | Stage | Finished when | Status |
|---|---|---|---|
| 1 | Site survey and requirements | All equipment identified, requirements agreed with my parents | In progress |
| 2 | Exact equipment data | Manuals and clean nameplates for everything the design depends on | Not started |
| 3 | Choosing sensors, safety check | Know what to measure on each part and with which sensor; an electrician checked everything on the mains side | Not started |
| 4 | Prototype on the desk | Sensors read correctly on my desk, low voltage only, nothing connected to the real unit | Not started |
| 5 | Firmware | Reads sensors, stores data, keeps working when a sensor is unplugged, Wi-Fi drops or it restarts | Not started |
| 6 | Server | Receives and checks data, saves it, has tests | Not started |
| 7 | App and notifications | Live status of each part, history, notifications to the phone tested | Not started |
| 8 | Collecting normal data | A few weeks of data from the working unit, so I know what "normal" looks like for each part | Not started |
| 9 | Anomalies and fault detection | Anomalies are logged, their frequency is tracked, faults point to a specific part | Not started |
| 10 | Full test on site | Works reliably in the real cold room, installation instructions written | Not started |

I don't start the next stage until the current one is really done.
